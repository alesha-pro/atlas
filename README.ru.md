# Атлас весов — интерактивное полотно для вскрытия моделей

Одно Miro-подобное полотно (pan/zoom, перелёты, миникарта), на котором модель
разложена на все весовые тензоры. Данные — реальные замеры из `atlas.jsonl`
(снимается `weight_atlas.py` с bf16-шардов): статистики распределений,
гистограммы log₂|w|, спектры, канальные отношения и фактический SQNR для
INT8-per-channel / INT4-g128 / FP8-e4m3.

Ничего модельно-специфичного в коде нет: слои, компоненты, ряды стены и
диапазоны метрик выводятся из самих данных.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # статика в dist/ — самодостаточна, хостится где угодно
```

## Регионы полотна

| Регион | Что показывает |
|---|---|
| **старт** | суть модели: параметры, слои, ритм полное/линейное внимание |
| **архитектура** | карта групп (embed → слои → attn/linattn → mlp → head, vision, mtp) с живыми числами и рельсой всех слоёв |
| **стена** | все тензоры: колонка = слой, ряд = роль; ряды выровнены, ритм 3:1 виден сразу; штриховка = метрика неприменима (1D) |
| **связи** | скаттер любая метрика × любая метрика + пресеты (хвост→INT4, горячие каналы→INT4…) |
| **глубина** | средняя метрика по слою от начала к концу стека + четверти |
| **гербарий** | тримап: площадь = параметры |
| **рекорды** | крайние точки (худший INT4, макс эксцесс, самый горячий канал…) |

Клик по любой клетке/точке/узлу открывает инспектор справа: вердикт простым
языком (из настоящих чисел), три SQNR, реальная гистограмма, спектр
сингулярных значений, канальные отношения, перцентили. Поиск по имени тензора
в шапке — с перелётом к клетке на стене. Цвет всего полотна управляется
переключателем метрики в шапке.

Интерфейс двуязычный: **EN по умолчанию**, переключатель EN/RU в шапке
(выбор запоминается в localStorage, вид и метрика при переключении
сохраняются). Все строки живут в `src/i18n.ts`. Селектор модели в шапке
виден всегда, даже пока модель одна.

## Как добавить модель

1. Снять атлас: `weight_atlas.py` из `research/voice-model/scripts/`
   (репо agents/x) по оригинальным шардам.
2. Положить: `public/models/<slug>/atlas.jsonl`
3. Добавить запись в `public/models/manifest.json`:
   ```json
   { "slug": "<slug>", "name": "Имя модели", "note": "как снималось" }
   ```
Всё. При нескольких моделях в шапке появляется переключатель.

Ожидаемые поля строки jsonl: `name, shape, dtype, numel, mean, std, absmax,
absmean, p50…p9999, kurtosis, skew, sparsity, outlier_3s/4s/6s, dyn_range,
hist_log2[29], component, layer, shard`, для 2D дополнительно
`row_amax_ratio, col_amax_ratio, sqnr_int8_ch, sqnr_int4_g128, sqnr_fp8_e4m3,
sv_top[12], stable_rank, sv_decay`. Отсутствующие метрики отображаются как
«неприменимо», а не ноль.

## Структура

```
src/
  data.ts        # парсинг jsonl, слои/группы/слоты/метрики — всё выводится из данных
  color.ts       # oklch-шкала, цвета «пород», штриховка н/п
  world.ts       # движок полотна: pan/zoom/flyTo
  store.ts       # состояние (метрика, выбор) + тултип
  panel.ts       # инспектор тензора/слоя/группы
  ui.ts          # шапка, поиск, туры, зум, миникарта
  sections/      # регионы: intro, arch, wall, scatter, treemap, records, depth
```

Стек: Vite + TypeScript, ноль рантайм-зависимостей. Стиль — «тёплая бумага»
(Spectral + IBM Plex Mono, oklch-шкала терракота→волна) из дизайн-прототипов
`Визуализация архитектуры LLM.zip`.
